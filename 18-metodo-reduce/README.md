# Método reduce


## ✅ Nível Fácil

1. **Somar todos os números de um array** — Dado um array de números, calcule a soma total dos elementos.
2. **Contar quantas letras “a” existem em um array de strings** — Dado um array de strings, conte quantas vezes a letra “a” aparece em todas as palavras.
3. **Concatenar um array de strings em uma única frase** — Dado um array de palavras, una todas em uma única string separada por espaços.
4. **Encontrar o maior número em um array** — Dado um array de números, use reduce para encontrar o maior valor.

## 🟡 Nível Médio

1. **Calcular a média dos números em um array** — Dado um array de números, calcule a média aritmética dos elementos.
2. **Contar quantos objetos têm propriedade “ativo” igual a true** — Dado um array de objetos com a propriedade `ativo`, conte quantos objetos estão ativos.
3. **Agrupar strings por sua primeira letra** — Dado um array de strings, agrupe-as em um objeto onde as chaves são as primeiras letras e os valores são arrays com as strings correspondentes.
4. **Somar valores de uma propriedade específica em um array de objetos** — Dado um array de objetos com a propriedade `preco`, calcule a soma total dos preços.

## 🔴 Nível Difícil

1. **Transformar um array de objetos em um objeto indexado por id** — Dado um array de objetos com a propriedade `id`, use reduce para criar um objeto onde as chaves são os ids e os valores os objetos correspondentes.
2. **Contar a frequência de palavras em um array de strings** — Dado um array de palavras, use reduce para criar um objeto que mapeie cada palavra à sua quantidade de ocorrências.
3. **Calcular o saldo final dado um array de transações** — Dado um array de objetos representando transações (com valor positivo ou negativo), calcule o saldo final somando todos os valores.
4. **Mesclar arrays aninhados em um único array único** — Dado um array que contém outros arrays, use reduce para juntar todos os elementos em um único array plano (flatten).
