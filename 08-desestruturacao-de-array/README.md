# Desestruturação de Array


## ✅ Nível Fácil

1. **Desestruture os dois primeiros nomes** — Dado um array com nomes de pessoas, extraia apenas os dois primeiros nomes usando desestruturação e exiba-os.
2. **Ignore os dois primeiros itens** — Dado um array com 5 frutas, extraia apenas o 3º, 4º e 5º item, ignorando os dois primeiros com desestruturação.
3. **Trocar valores de posição usando desestruturação** — Dado um array `[a, b]`, use desestruturação para trocar os valores de `a` e `b`.
4. **Desestruture e exiba o último item do array** — Dado um array de números com 4 posições, use desestruturação parcial para pegar apenas o último valor.

## 🟡 Nível Médio

1. **Desestruture arrays aninhados** — Dado um array que contém outro array dentro dele, extraia os valores internos diretamente via desestruturação.
2. **Use desestruturação em parâmetros de função** — Crie uma função que receba um array com 3 valores e, diretamente na declaração da função, use desestruturação para extrair os elementos.
3. **Extrair apenas os valores pares com desestruturação seletiva** — Dado um array com 6 números alternando entre ímpares e pares, desestruture apenas os valores pares.
4. **Desestruturação com valor padrão** — Dado um array com 2 elementos, desestruture como se houvesse 3, e defina um valor padrão para o terceiro item que está ausente.

## 🔴 Nível Difícil

1. **Desestruture valores com `rest operator`** — Dado um array com 10 nomes, extraia os dois primeiros e use o `rest` para armazenar os demais em uma nova variável.
2. **Mistura de desestruturação e loop** — Crie um array de arrays, onde cada item é uma tupla com nome e idade. Use desestruturação dentro de um loop para acessar os dois valores em cada iteração.
3. **Desestruture um retorno de função com múltiplos valores** — Crie uma função que retorna um array com 3 valores diferentes (por exemplo, [status, mensagem, código]). Use desestruturação para capturar esses valores ao chamar a função.
4. **Desestruturação condicional com fallback** — Dado um array de configurações que pode estar incompleto (ex: `[tema, idioma]`), desestruture os itens, fornecendo valores padrões caso estejam ausentes, e use lógica condicional para exibir um aviso caso algum item esteja indefinido.
