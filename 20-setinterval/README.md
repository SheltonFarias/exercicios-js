# setInterval


## ✅ Nível Fácil

1. **Exibir uma mensagem no console a cada 2 segundos** — Implemente um temporizador que mostre uma mensagem no console a cada 2 segundos.
2. **Atualizar um contador simples na página a cada 1 segundo** — Mostre um contador numérico na página que aumenta a cada segundo.
3. **Piscar uma cor de fundo alternando a cada 1 segundo** — Alterne a cor de fundo de um elemento entre duas cores a cada 1 segundo.
4. **Mostrar um alerta a cada 5 segundos** — Dispare um alerta no navegador a cada 5 segundos (com opção para parar depois).

## 🟡 Nível Médio

1. **Criar um relógio digital que atualiza a cada segundo** — Mostre o horário atual formatado (horas:minutos:segundos) atualizando a cada segundo.
2. **Atualizar uma lista de notícias simuladas a cada 10 segundos** — Simule a atualização de uma lista de notícias, substituindo os itens a cada 10 segundos.
3. **Desativar um botão após 15 segundos de clique, habilitando novamente após outros 15 segundos** — Ao clicar no botão, ele fica desativado por 15 segundos e depois volta a funcionar.
4. **Alterar o texto de um parágrafo alternando entre duas mensagens a cada 3 segundos** — Troque o texto exibido em um parágrafo entre duas mensagens diferentes a cada 3 segundos.

## 🔴 Nível Difícil

1. **Criar um temporizador regressivo (countdown) que atualiza a cada segundo usando `setInterval`** — Implemente um contador regressivo que começa em 30 e decrementa a cada segundo até zero.
2. **Simular uma rolagem automática de imagens (slider) com troca a cada 4 segundos** — Implemente um slider de imagens que muda automaticamente para a próxima imagem a cada 4 segundos.
3. **Parar o `setInterval` após uma condição específica (exemplo: após 20 execuções)** — Execute uma ação a cada segundo, mas pare o temporizador depois que ele for executado 20 vezes.
4. **Combinar `setInterval` com eventos do usuário para pausar e retomar a execução** — Crie um temporizador que exiba um número a cada segundo, e permita pausar e retomar essa contagem com botões.
