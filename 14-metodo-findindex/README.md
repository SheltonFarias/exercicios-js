# Método findIndex


## ✅ Nível Fácil

1. **Encontrar o índice do número 10** — Dado um array de números, encontre o índice do número 10.
2. **Encontrar o índice da primeira palavra que começa com “B”** — Dado um array de strings, encontre o índice da primeira palavra que começa com a letra “B”.
3. **Encontrar o índice do valor falso** — Dado um array de valores booleanos, encontre o índice do primeiro valor `false`.
4. **Encontrar o índice do número maior que 50** — Dado um array de números, encontre o índice do primeiro número maior que 50.

## 🟡 Nível Médio

1. **Encontrar o índice do objeto com propriedade “id” igual a 3** — Dado um array de objetos, encontre o índice do objeto que tenha `id` igual a 3.
2. **Encontrar o índice do primeiro objeto com status “ativo”** — Dado um array de objetos com a propriedade `status`, encontre o índice do primeiro objeto cujo status seja “ativo”.
3. **Encontrar o índice da primeira string com tamanho maior que 5** — Dado um array de strings, encontre o índice da primeira string que tenha mais de 5 caracteres.
4. **Encontrar o índice do primeiro número negativo** — Dado um array de números, encontre o índice do primeiro número negativo.

## 🔴 Nível Difícil

1. **Encontrar o índice do objeto com propriedade aninhada específica** — Dado um array de objetos, cada um contendo uma propriedade aninhada `endereco.cidade`, encontre o índice do primeiro objeto cuja cidade seja “Rio de Janeiro”.
2. **Encontrar o índice do primeiro objeto que satisfaça múltiplas condições** — Dado um array de objetos, encontre o índice do primeiro objeto que tenha `idade` maior que 18 **e** `status` igual a “ativo”.
3. **Encontrar o índice usando `findIndex` dentro de arrays aninhados** — Dado um array de arrays, encontre o índice do primeiro sub-array que contenha um número maior que 100.
4. **Encontrar o índice com fallback para caso não encontrado** — Implemente uma busca pelo índice de um valor numérico; caso o valor não exista, retorne `-1` e exiba uma mensagem personalizada.
