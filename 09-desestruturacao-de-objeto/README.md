# Desestruturação de objeto


## ✅ Nível Fácil

1. **Desestruture propriedades básicas** — Dado um objeto com as propriedades `nome` e `idade`, extraia esses valores e exiba-os.
2. **Desestruturação com renomeação** — Dado um objeto com a propriedade `nome`, extraia-a renomeando para `nomeCompleto`.
3. **Extraia apenas uma propriedade** — Dado um objeto com várias propriedades, extraia somente a propriedade `email`.
4. **Desestruturação com valor padrão** — Dado um objeto que pode ou não ter a propriedade `telefone`, extraia-a definindo um valor padrão caso ela não exista.

## 🟡 Nível Médio

1. **Desestruture propriedades aninhadas** — Dado um objeto com a estrutura `{ endereco: { rua, numero } }`, extraia `rua` e `numero` diretamente.
2. **Desestruturação em parâmetros de função** — Crie uma função que recebe um objeto com as propriedades `nome` e `idade` e desestruture esses valores já no parâmetro da função.
3. **Desestruture múltiplos objetos** — Dado dois objetos com as mesmas propriedades, extraia as propriedades `nome` de ambos em variáveis diferentes.
4. **Desestruturação com resto (`rest`)** — Dado um objeto com várias propriedades, extraia algumas específicas e agrupe o restante em um novo objeto usando o operador `rest`.

## 🔴 Nível Difícil

1. **Desestruturação com alias e valor padrão para propriedades aninhadas** — Dado um objeto complexo com vários níveis, extraia uma propriedade aninhada, renomeando-a e definindo um valor padrão caso não exista.
2. **Desestruture objetos dentro de arrays** — Dado um array de objetos, extraia uma propriedade específica de cada objeto usando desestruturação dentro de um loop.
3. **Desestruturação com combinação de arrays e objetos** — Dado um objeto que possui uma propriedade que é um array de objetos, extraia propriedades dos objetos internos com desestruturação dupla.
4. **Desestruturação condicional com fallback** — Dado um objeto que pode ter propriedades faltando, extraia os valores usando desestruturação com valores padrão e aplique lógica condicional para tratar casos indefinidos.
