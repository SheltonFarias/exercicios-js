# Método some


## ✅ Nível Fácil

1. **Verificar se existe algum número negativo** — Dado um array de números, verifique se existe pelo menos um número negativo.
2. **Checar se alguma palavra começa com “J”** — Dado um array de strings, verifique se alguma palavra começa com a letra “J”.
3. **Confirmar se há algum valor falso no array** — Dado um array de valores booleanos, confirme se algum valor é `false`.
4. **Verificar se existe algum número maior que 100** — Dado um array de números, confirme se existe algum número maior que 100.

## 🟡 Nível Médio

1. **Verificar se algum objeto tem propriedade `ativo` igual a false** — Dado um array de objetos com propriedade `ativo`, verifique se algum objeto tem `ativo` como `false`.
2. **Checar se alguma string contém a substring “JS”** — Dado um array de strings, verifique se alguma contém a substring “JS”.
3. **Confirmar se algum número está fora de um intervalo** — Dado um array de números, verifique se existe algum número menor que 10 ou maior que 50.
4. **Verificar se algum usuário tem mais de 60 anos** — Dado um array de objetos usuário, verifique se algum tem idade maior que 60.

## 🔴 Nível Difícil

1. **Verificar se algum objeto tem propriedade aninhada específica** — Dado um array de objetos que possuem um endereço, verifique se algum objeto tem cidade igual a “São Paulo”.
2. **Checar se alguma string está duplicada no array** — Dado um array de strings, verifique se alguma string aparece mais de uma vez.
3. **Confirmar se algum número em arrays aninhados atende a uma condição** — Dado um array de arrays numéricos, verifique se algum número em qualquer sub-array é negativo.
4. **Verificar se algum objeto atende a múltiplas condições** — Dado um array de objetos, verifique se existe pelo menos um objeto com `status` “ativo” e `idade` maior que 30.
