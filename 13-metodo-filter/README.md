# Método filter


## ✅ Nível Fácil

1. **Filtrar números pares** — Dado um array de números, filtre apenas os números pares.
2. **Filtrar strings que começam com letra ‘A’** — Dado um array de palavras, retorne somente as que começam com a letra “A”.
3. **Filtrar valores verdadeiros** — Dado um array com valores variados (true, false, null, undefined, 0, 1), filtre apenas os valores considerados verdadeiros.
4. **Filtrar nomes com mais de 5 letras** — Dado um array de nomes, filtre os nomes que tenham mais de 5 caracteres.

## 🟡 Nível Médio

1. **Filtrar objetos com idade maior que 18** — Dado um array de objetos com propriedade `idade`, filtre somente os que têm idade maior que 18.
2. **Filtrar produtos em estoque** — Dado um array de objetos produto, cada um com propriedade `emEstoque` (booleano), filtre os produtos que estão em estoque.
3. **Filtrar strings que contenham uma substring** — Dado um array de strings, filtre as que contenham a substring “JS”.
4. **Filtrar números dentro de um intervalo** — Dado um array de números, filtre os números que estejam entre 10 e 50.

## 🔴 Nível Difícil

1. **Filtrar objetos com múltiplas condições** — Dado um array de objetos com `idade` e `status`, filtre os objetos que tenham idade maior que 18 **e** status igual a “ativo”.
2. **Filtrar duplicatas removendo itens repetidos** — Dado um array com valores repetidos, filtre para retornar apenas os valores únicos (sem duplicatas).
3. **Filtrar itens com propriedades aninhadas específicas** — Dado um array de objetos que têm uma propriedade aninhada (ex: `{ endereco: { cidade } }`), filtre os objetos cuja cidade seja “São Paulo”.
4. **Filtrar e mapear ao mesmo tempo usando filter com map** — Crie um processo onde primeiro filtra um array para valores válidos e depois mapeia os valores filtrados para outra forma, usando `filter` e `map` encadeados.
