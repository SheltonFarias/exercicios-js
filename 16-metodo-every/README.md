# Método every


## ✅ Nível Fácil

1. **Verificar se todos os números são positivos** — Dado um array de números, verifique se todos são maiores que zero.
2. **Checar se todas as strings têm mais de 3 letras** — Dado um array de palavras, confirme se todas têm mais de três caracteres.
3. **Confirmar se todos os valores são booleanos** — Dado um array, verifique se todos os valores são do tipo booleano.
4. **Verificar se todos os números são pares** — Dado um array de números, confirme se todos são pares.

## 🟡 Nível Médio

1. **Verificar se todos os objetos têm propriedade “ativo” igual a true** — Dado um array de objetos, confirme se todos têm a propriedade `ativo` como `true`.
2. **Checar se todas as strings começam com letra maiúscula** — Dado um array de strings, verifique se todas começam com letra maiúscula.
3. **Confirmar se todos os números estão dentro de um intervalo** — Dado um array de números, confirme se todos estão entre 10 e 50.
4. **Verificar se todas as senhas possuem mais de 8 caracteres** — Dado um array de senhas (strings), confirme se todas têm comprimento maior que 8.

## 🔴 Nível Difícil

1. **Verificar se todos os objetos têm propriedade aninhada válida** — Dado um array de objetos com propriedade aninhada, como `endereco.cidade`, confirme se todos os objetos têm essa propriedade preenchida.
2. **Confirmar se todos os números em arrays aninhados são positivos** — Dado um array de arrays numéricos, confirme se todos os números em todos os arrays são positivos.
3. **Verificar se todos os objetos satisfazem múltiplas condições** — Dado um array de objetos, confirme se todos têm `idade` maior que 18 **e** `status` igual a “ativo”.
4. **Checar se todas as strings são únicas (sem repetição)** — Dado um array de strings, confirme se não há strings duplicadas (todas são únicas).
