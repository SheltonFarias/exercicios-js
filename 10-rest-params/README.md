# Rest params


## ✅ Nível Fácil

1. **Função que soma todos os números recebidos** — Crie uma função que recebe um número variável de argumentos e retorna a soma de todos eles usando rest parameters.
2. **Função que retorna a quantidade de argumentos passados** — Implemente uma função que conta quantos argumentos foram recebidos usando rest.
3. **Função que exibe todos os argumentos em ordem inversa** — Crie uma função que recebe vários argumentos e imprime eles na ordem inversa usando rest.
4. **Separar o primeiro argumento dos demais** — Crie uma função que recebe múltiplos argumentos, separa o primeiro do resto usando rest, e imprime ambos separadamente.

## 🟡 Nível Médio

1. **Concatene múltiplos arrays passados como argumentos** — Crie uma função que recebe vários arrays como argumentos (usando rest), e retorna um único array contendo todos os elementos concatenados.
2. **Função que filtra números pares de múltiplos argumentos** — Receba múltiplos números e retorne apenas os pares usando rest para capturar os parâmetros.
3. **Função que cria um perfil de usuário** — Recebe um nome e uma lista variável de interesses com rest parameters e retorne um objeto com nome e interesses em array.
4. **Função que recebe múltiplos objetos e mescla em um só** — Receba múltiplos objetos usando rest e retorne um único objeto resultante da fusão (merge) de todos.

## 🔴 Nível Difícil

1. **Função que calcula média ignorando os dois primeiros argumentos** — Receba vários números usando rest e calcule a média apenas dos valores depois dos dois primeiros argumentos.
2. **Função que chama outra função passando alguns argumentos fixos e o resto variado** — Implemente uma função que chama outra função interna passando parâmetros fixos e o resto dos argumentos variáveis usando rest.
3. **Função que recebe múltiplos arrays e retorna um array de arrays invertidos** — Receba múltiplos arrays e retorne um array onde cada item é o array original invertido.
4. **Função que recebe argumentos variáveis e agrupa por tipo (string, number, boolean, etc.)** — Receba múltiplos argumentos e retorne um objeto agrupando os argumentos conforme seu tipo.
