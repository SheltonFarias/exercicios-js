# Método construtor


## ✅ Nível Fácil

1. **Classe Pessoa** — Crie uma classe `Pessoa` com `nome` e `idade` passados via `constructor`. Crie uma instância e exiba os dados no console.
2. **Classe Produto** — Monte uma classe `Produto` com `nome`, `preco` e `quantidade`. Instancie 3 produtos diferentes e exiba-os.
3. **Classe Carro com método de exibição** — Crie uma classe `Carro` com `marca`, `modelo` e `ano`. Adicione um método que exiba os dados do carro como uma frase.
4. **Classe Animal com som** — Crie uma classe `Animal` com `tipo` e `som`. Adicione um método `emitirSom()` que imprime o som associado ao animal.

## 🟡 Nível Médio

1. **Classe Conta Bancária** — Crie uma classe `ContaBancaria` com `titular` e `saldo`. Adicione métodos `depositar(valor)` e `sacar(valor)` com verificação de saldo.
2. **Classe Livro com método de resumo** — Crie uma classe `Livro` com `titulo`, `autor` e `ano`. Adicione um método `resumo()` que retorna uma string formatada com essas informações.
3. **Classe Aluno com média** — Crie uma classe `Aluno` com `nome` e um array de `notas`. Adicione um método que calcula e retorna a média do aluno.
4. **Classe Retângulo com área e perímetro** — Crie uma classe `Retangulo` com `largura` e `altura`. Adicione métodos `calcularArea()` e `calcularPerimetro()`.

## 🔴 Nível Difícil

1. **Classe Fatura com cálculo de total** — Crie uma classe `Fatura` com lista de produtos (cada um com nome, quantidade e preço unitário). Adicione um método que calcula o valor total da fatura.
2. **Classe Agenda com cadastro e busca** — Crie uma classe `Agenda` que armazena pessoas com nome e telefone. Implemente métodos para adicionar e buscar contatos.
3. **Classe Filme com validação de classificação** — Crie uma classe `Filme` com `titulo`, `genero` e `classificacao`. Adicione um método que bloqueia filmes inadequados para menores de 14 anos.
4. **Sistema de Login com usuários** — Crie uma classe `Usuario` com `nome`, `email`, `senha`. Crie uma classe `SistemaLogin` com método `autenticar(email, senha)` que verifica se o login é válido em um array de usuários.
