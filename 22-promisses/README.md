# Promisses


## ✅ Nível Fácil

1. **Criar uma Promise que resolve depois de 1 segundo** — Faça uma Promise que resolve com uma mensagem após 1 segundo.
2. **Criar uma Promise que rejeita com um erro simples** — Implemente uma Promise que rejeita com uma mensagem de erro.
3. **Encadear then para manipular o resultado de uma Promise** — Crie uma Promise e use `then` para transformar o valor resolvido.
4. **Tratar rejeição de uma Promise com catch** — Mostre como capturar um erro rejeitado com `catch`.

## 🟡 Nível Médio

1. **Criar uma função que retorna uma Promise que resolve com dados simulados** — Simule uma requisição que retorna dados após delay.
2. **Usar Promise.all para aguardar múltiplas Promises** — Aguarde várias Promises e processe seus resultados juntos.
3. **Usar Promise.race para pegar a primeira Promise que resolver** — Dado várias Promises, obtenha o resultado da que terminar primeiro.
4. **Criar uma Promise que resolve ou rejeita baseado em condição** — Implemente uma Promise que decide resolver ou rejeitar conforme um parâmetro.

## 🔴 Nível Difícil

1. **Encadear múltiplas Promises para executar operações sequenciais** — Execute operações assíncronas uma após a outra usando then.
2. **Criar uma função que reintenta uma Promise falha até um limite** — Faça uma função que tenta executar uma Promise várias vezes até resolver ou atingir limite.
3. **Combinar Promises para tratar dados complexos aninhados** — Use Promises para manipular dados que dependem de outros dados assíncronos.
4. **Implementar tratamento de erros customizado para Promises rejeitadas** — Personalize o tratamento de erros para diferentes tipos de rejeições em Promises.
