# Método map


## ✅ Nível Fácil

1. **Multiplicar todos os números por 2** — Dado um array de números, crie um novo array onde cada número é multiplicado por 2.
2. **Converter array de nomes para maiúsculas** — Dado um array de strings (nomes), crie um novo array onde todos os nomes estejam em letras maiúsculas.
3. **Extrair a primeira letra de cada palavra** — Dado um array de palavras, crie um novo array com apenas a primeira letra de cada palavra.
4. **Adicionar prefixo “Item:” em cada string** — Dado um array de strings, crie um novo array onde cada string é precedida do texto “Item: ”.

## 🟡 Nível Médio

1. **Extrair uma propriedade específica de um array de objetos** — Dado um array de objetos, extraia um array apenas com os valores de uma propriedade, por exemplo, `nome`.
2. **Criar array de objetos a partir de um array de strings** — Dado um array de nomes, transforme-o em um array de objetos onde cada objeto tenha a propriedade `nome`.
3. **Converter preços de dólares para reais** — Dado um array de objetos com preços em dólares, crie um novo array onde os preços estão convertidos para reais (suponha taxa fixa).
4. **Formatar datas em strings legíveis** — Dado um array de objetos com datas no formato ISO, crie um array de strings formatadas (ex: “13/06/2025”).

## 🔴 Nível Difícil

1. **Aninhar mapas para extrair dados profundos** — Dado um array de objetos, cada um contendo um array interno, use map duas vezes para extrair e transformar os dados internos.
2. **Mapear e filtrar em uma única operação** — Crie uma operação onde você mapeia um array transformando os dados, mas retorna `null` para itens que não atendem a uma condição, e depois remova os `null`.
3. **Mapear um array de arrays e calcular somas internas** — Dado um array de arrays numéricos, use map para criar um novo array com a soma dos números de cada sub-array.
4. **Atualizar profundamente um array de objetos aninhados** — Dado um array de objetos que contém arrays aninhados, use map para atualizar uma propriedade específica em todos os objetos internos, retornando um novo array atualizado.
