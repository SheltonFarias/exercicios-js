# setTimeout


## ✅ Nível Fácil

1. **Exibir uma mensagem no console após 3 segundos** — Mostre no console uma mensagem simples após um atraso de 3 segundos.
2. **Mudar o texto de um botão após 5 segundos** — Em uma página web, altere o texto de um botão depois de 5 segundos de carregada a página.
3. **Mostrar um alerta após 2 segundos** — Dispare um alerta do navegador 2 segundos após o usuário clicar em um botão.
4. **Esconder uma imagem após 4 segundos** — Faça com que uma imagem desapareça (esconda) 4 segundos depois de ser exibida.

## 🟡 Nível Médio

1. **Exibir uma sequência de mensagens com intervalo** — Mostre três mensagens diferentes no console, cada uma com 2 segundos de intervalo entre elas.
2. **Alterar a cor de fundo de uma div após 3 segundos** — Depois de 3 segundos, altere a cor de fundo de uma div para azul.
3. **Bloquear um botão por 5 segundos após ser clicado** — Quando um botão for clicado, desabilite-o por 5 segundos e depois reabilite.
4. **Atualizar um contador na página a cada 1 segundo, mas parar após 10 segundos** — Use `setTimeout` (em conjunto com recursão, não `setInterval`) para atualizar um contador exibido na página a cada 1 segundo, parando depois de 10 atualizações.

## 🔴 Nível Difícil

1. **Criar uma função que simula um “loading” com mensagens diferentes a cada 1 segundo** — Mostre mensagens como “Carregando.”, “Carregando..”, “Carregando...” em loop, mudando a cada segundo.
2. **Executar múltiplas funções com delays diferentes** — Faça uma sequência onde três funções diferentes são executadas com delays de 1s, 3s e 5s, respectivamente.
3. **Criar um cronômetro regressivo que atualiza a cada segundo usando `setTimeout` recursivamente** — Implemente um cronômetro regressivo (countdown) que começa em 10 e diminui a cada segundo até zero.
4. **Simular uma chamada assíncrona que resolve depois de um tempo usando `setTimeout` dentro de uma Promise** — Crie uma função que retorna uma Promise que é resolvida após 3 segundos usando `setTimeout`.
