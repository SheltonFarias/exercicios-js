# Switch


## ✅ Nível Fácil

1. **Dia da Semana** — Peça ao usuário um número de 1 a 7 e exiba o nome do dia correspondente (1 = Domingo, 2 = Segunda, ..., 7 = Sábado). Utilize `switch` para mapear cada valor.
2. **Nível de Escolaridade** — Peça ao usuário para digitar uma letra correspondente ao seu nível de escolaridade: - `F`: Fundamental - `M`: Médio - `S`: Superior Mostre a descrição conforme a letra escolhida.
3. **Sinal de Trânsito** — Solicite ao usuário uma cor (vermelho, amarelo ou verde). Com base na cor, informe a ação: - Vermelho → "Pare" - Amarelo → "Atenção" - Verde → "Siga"
4. **Tipo de Animal** — Peça o nome de um animal (gato, cachorro, peixe, etc.). Mostre se ele é um **mamífero**, **réptil**, **ave** ou **outro**, usando `switch`.

## 🟡 Nível Médio

1. **Calculadora Simples** — Solicite dois números e uma operação (+, -, *, /). Use `switch` para realizar a operação escolhida e exiba o resultado.
2. **Nota por Letra** — Peça ao usuário que digite uma letra representando uma nota: - `A`, `B`, `C`, `D`, `F` Mostre a mensagem correspondente: - A → Excelente - B → Bom - C → Regular - D → Ruim - F → Reprovado
3. **Tipo de Combustível** — Solicite o tipo de combustível desejado (A - Álcool, G - Gasolina, D - Diesel) e exiba a mensagem com o tipo escolhido.
4. **Mês por Número** — Peça um número de 1 a 12 e mostre o nome do mês correspondente. Ex: 1 → Janeiro, 12 → Dezembro.

## 🔴 Nível Difícil

1. **Plano de Assinatura** — Solicite ao usuário o plano contratado (Básico, Padrão, Premium). Com base no plano, exiba os recursos disponíveis. Exemplo: - Básico → 1 tela, SD - Padrão → 2 telas, HD - Premium → 4 telas, Full HD
2. **Conversor de Moedas** — Peça ao usuário o código da moeda desejada (USD, EUR, GBP, BRL). Exiba a taxa de conversão fictícia com base no código.
3. **Simulador de Menu de Restaurante** — Mostre um menu com opções numeradas (1 a 5). Solicite a escolha do usuário e exiba o prato correspondente. Caso digite um número inválido, avise.
4. **Classificação de Produto por Código** — Peça um código numérico de 1 a 10 e classifique o produto como: - 1 a 3 → Categoria A - 4 a 6 → Categoria B - 7 a 9 → Categoria C - 10 → Categoria Especial Use `switch` com múltiplos `case` agrupados.
