# Dom


## 🟡 Nível Médio

1. **Contador com botões** — Crie um número exibido na tela e dois botões: "+" e "-". Ao clicar, o número deve aumentar ou diminuir em 1.
2. **Lista dinâmica de tarefas** — Crie um campo de texto e um botão "Adicionar". Ao clicar, adicione o valor digitado em uma lista (`<ul>`), como um novo item (`<li>`).
3. **Validação de formulário simples** — Crie um formulário com campos de nome e email. Quando o botão "Enviar" for clicado, verifique se os campos estão preenchidos e exiba uma mensagem de erro ou sucesso abaixo.
4. **Mudar imagem ao clicar** — Exiba uma imagem na tela e três botões com nomes diferentes. Cada botão deve trocar a imagem exibida por outra relacionada ao nome do botão.

## 🔴 Nível Difícil

1. **Simulador de carrinho de compras** — Crie uma lista de produtos com botões "Adicionar ao carrinho". Ao clicar, o produto deve aparecer em uma lista de carrinho com nome e preço. Mostre o total atualizado.
2. **Calculadora simples interativa** — Monte uma interface com dois campos de número e quatro botões para operações (+, -, *, /). Ao clicar, exiba o resultado da operação abaixo.
3. **Validação de senha com força** — Peça ao usuário para digitar uma senha e, à medida que digita, mostre a força dela (fraca, média, forte) com base no tamanho e nos caracteres usados.
4. **Quiz interativo com pontuação final** — Crie 3 perguntas com múltipla escolha (radio buttons). Após clicar em "Finalizar", exiba quantas respostas estão corretas e uma mensagem com o resultado final.
