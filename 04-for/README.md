# For


## ✅ Nível Fácil

1. **Contar de 1 a 10** — Exiba no console os números de 1 até 10 utilizando um laço `for`.
2. **Contar números pares de 0 a 20** — Utilize um `for` para mostrar somente os números pares entre 0 e 20.
3. **Tabuada do 5** — Use um `for` para exibir a tabuada do 5 (de 5x1 até 5x10) no console ou na tela.
4. **Contagem regressiva de 10 até 0** — Crie um laço `for` que exiba os números de 10 até 0 em ordem decrescente.

## 🟡 Nível Médio

1. **Somar números de 1 a 100** — Use um `for` para calcular e exibir a soma de todos os números de 1 a 100.
2. **Fatorial de um número** — Peça ao usuário um número e use um `for` para calcular o fatorial desse número (ex: 5! = 120).
3. **Contar vogais em uma palavra** — Peça uma palavra ao usuário e use um `for` para percorrer cada letra, contando quantas vogais existem.
4. **Criar uma lista de nomes formatada** — Dado um array com nomes, use um `for` para exibir todos os nomes precedidos pelo índice, exemplo: `1 - João`, `2 - Maria`, etc.

## 🔴 Nível Difícil

1. **Verificar se um número é primo** — Peça um número ao usuário e use um `for` para verificar se ele é primo (só divisível por 1 e por ele mesmo).
2. **Desenhar um triângulo com asteriscos** — Peça ao usuário um número e use `for` para desenhar no console um triângulo com esse número de linhas, como: ``` markdown CopiarEditar * ** *** **** ```
3. **Inverter uma string** — Peça ao usuário uma palavra e, com `for`, exiba a mesma palavra ao contrário.
4. **Encontrar o maior número de um array** — Dado um array de números, use um `for` para percorrer e encontrar qual é o maior número presente no array.
