# Método find


## ✅ Nível Fácil

1. **Encontrar o número 7 no array** — Dado um array de números, encontre o primeiro número que seja exatamente 7.
2. **Encontrar a primeira palavra que termina com “a”** — Dado um array de strings, encontre a primeira palavra que termina com a letra “a”.
3. **Encontrar o primeiro valor falso no array** — Dado um array com valores booleanos, encontre o primeiro valor `false`.
4. **Encontrar o primeiro número maior que 100** — Dado um array de números, encontre o primeiro número maior que 100.

## 🟡 Nível Médio

1. **Encontrar o objeto com id igual a 10** — Dado um array de objetos com propriedade `id`, encontre o primeiro objeto cujo `id` seja 10.
2. **Encontrar o objeto com status “pendente”** — Dado um array de objetos que possuem uma propriedade `status`, encontre o primeiro objeto que tenha o status “pendente”.
3. **Encontrar a primeira string com mais de 8 caracteres** — Dado um array de strings, encontre a primeira que tenha mais de 8 caracteres.
4. **Encontrar o primeiro número negativo** — Dado um array de números, encontre o primeiro número negativo.

## 🔴 Nível Difícil

1. **Encontrar o objeto cuja propriedade aninhada “endereco.cidade” seja “Curitiba”** — Dado um array de objetos, cada um contendo um objeto `endereco` com propriedade `cidade`, encontre o primeiro objeto onde a cidade seja “Curitiba”.
2. **Encontrar o objeto que satisfaça múltiplas condições** — Dado um array de objetos, encontre o primeiro que tenha `idade` maior que 21 **e** `ativo` como `true`.
3. **Encontrar o elemento dentro de arrays aninhados** — Dado um array de arrays numéricos, encontre o primeiro número maior que 500, navegando pelos arrays internos.
4. **Encontrar o elemento com fallback** — Procure um elemento específico; caso não seja encontrado, trate o resultado para exibir uma mensagem informando que não foi achado.
